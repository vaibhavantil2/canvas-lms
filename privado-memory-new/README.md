## Features
- [Create Course](features/create-course.md) — Instructors can create new courses to organize learning material and enroll participants.
- [Enroll Student](features/enroll-student.md) — Administrators or instructors can enroll students (or other users) into a course.
- [Create Assignment](features/create-assignment.md) — Instructors can create assignments, set due dates, point values, and attach resources.
- [Grade Submission](features/grade-submission.md) — Instructors can view, comment on, and assign grades to student submissions.
- [Quiz Management](features/quiz-management.md) — Instructors can create, edit, and publish quizzes, and students can take them.
- [Discussion Forums](features/discussion-forums.md) — Users can start discussion topics, reply, and engage in threaded conversations.
- [File Management](features/file-management.md) — Users can upload, view, download, and organize files within a course.
- [Announcements](features/announcements.md) — Instructors can post announcements that appear prominently for all course participants.
- [Gradebook](features/gradebook.md) — Provides a centralized view for instructors to see and edit grades across all assignments.
- [User Authentication & SSO](features/user-authentication-sso.md) — Handles login, logout, and single‑sign‑on via multiple providers (SAML, OAuth, LDAP, etc.).
- [External Tool Integration (LTI)](features/external-tool-integration-lti.md) — Allows courses to launch and interact with external learning tools via LTI standards.
- [Content Export & Import](features/content-export-import.md) — Instructors can export a course’s content for backup or migration and import content into a course.
- [Wiki Pages](features/wiki-pages.md) — Course participants can create, edit, and view collaborative wiki pages.
- [Rubric Management](features/rubric-management.md) — Instructors can create rubrics to standardize grading criteria and apply them to assignments.
- [Calendar & Scheduling](features/calendar-scheduling.md) — Provides a calendar view for events, due dates, and meetings within a course.
- [Conferences (Webinars)](features/conferences-webinars.md) — Instructors can schedule and host live video conferences for synchronous instruction.
- [Notifications & Alerts](features/notifications-alerts.md) — Sends real‑time and email notifications for assignment due dates, grades, announcements, etc.
- [Group & Collaboration Management](features/group-collaboration-management.md) — Allows creation of groups, group sets, and collaborative projects within a course.
- [Live Assessments](features/live-assessments.md) — Provides real‑time assessment experiences (e.g., polls, quizzes) during live sessions.
